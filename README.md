## Описание

**Random Task Generator** — это десктопное GUI-приложение на Python (tkinter), которое генерирует случайные задачи из предопределённого списка. Приложение помогает побороть прокрастинацию и мотивирует к действию: нажал кнопку — получил задачу!

### Возможности

| Функция | Описание |
|---|---|
|  Генерация задачи | Случайный выбор задачи из списка |
|  Фильтрация | По категориям: Учёба / Спорт / Работа |
|  Добавление задач | Добавление пользовательских задач с валидацией |
|  История | Просмотр всех сгенерированных задач |
|  Сохранение | История сохраняется в `history.json` и загружается при запуске |
|  Очистка | Сброс истории одним кликом |

## Примеры использования

### 1. Генерация случайной задачи

1. Запустите приложение (`python app.py`)
2. Нажмите кнопку **«🎲 Сгенерировать задачу»**
3. В карточке отобразится задача с цветным бейджем категории
4. Задача сохранится в истории справа

### 2. Фильтрация по категории

- Выберите фильтр **«Спорт»** — генератор будет выбирать только спортивные задачи
- Цвета категорий:
  - 🟢 Учёба
  - 🟠 Спорт
  - 🟣 Работа

### 3. Добавление своей задачи

1. Введите название в поле **«Название»** (минимум 3 символа, не должно быть пустым)
2. Выберите категорию из выпадающего списка
3. Нажмите **«Добавить»**

**Валидация при добавлении:**
- ❌ Пустое название → предупреждение
- ❌ Менее 3 символов → предупреждение
- ❌ Дубликат задачи → предупреждение
- ✅ Корректный ввод → задача добавляется в пул

### 4. История

- Справа отображается список всех сгенерированных задач в формате:
  `эмодзи ДД.ММ.ГГГГ ЧЧ:ММ:СС — Название задачи`
- История сохраняется в `history.json` и загружается при следующем запуске
- Кнопка **«🗑 Очистить»** сбрасывает историю (с подтверждением)

## Тесты (примеры ручного тестирования)

| # | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Нажать «Сгенерировать» без фильтра | Случайная задача из любой категории |
| 2 | Выбрать фильтр «Спорт», нажать «Сгенерировать» | Только задачи категории «спорт» |

| 6 | Закрыть и снова открыть приложение | История загружается из `history.json` |
| 7 | Нажать «Очистить» и подтвердить | История очищается |
| 8 | Нажать «Очистить» и отменить | История остаётся |
